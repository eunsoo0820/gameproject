# 항해 게임 프로젝트

- 대상: Windows PC, 유료 판매 예정.
- 장르: 3D 1인칭 항해 게임.
- 개발 순서: 싱글플레이 우선, 이후 멀티플레이 추가.
- Unity 프로젝트 위치: `Game/`.
- 생성에 사용한 에디터: 6000.5.9f1.
- 선택 템플릿: 3D URP (`com.unity.template.urp-blank`).
- 배 종류, 그래픽 스타일, 멀티플레이 인원과 방식은 미정.

## 설정 상태 (2026-10-05)

템플릿 파일은 생성되었으나, 활성 Unity Editor 라이선스가 없어 초기화가
종료 코드 198로 중단되었다. 프로젝트 생성 완료, 패키지 임포트, 컴파일,
에디터 실행은 아직 검증되지 않았다. ProjectVersion.txt도 아직 생성되지 않았다.

Unity Hub에서 로그인 및 적절한 라이선스 활성화를 완료한 뒤,
설치된 6000.5.9f1 에디터로 Game 폴더를 열어 초기화를 이어가야 한다.
기존 Git 저장소를 유지하며 자동 생성 폴더는 루트 .gitignore에서 제외한다.

## 제안한 첫 시제품 범위

1. 배 위에서 1인칭 이동과 시점 조작.
2. 조타 장치와 상호작용 및 배 운전.
3. 바다와 작은 섬에서 항해 및 정박.

멀티플레이 확장을 고려해 플레이어 입력과 배·월드 상태를 분리하는 방향으로 설계한다.
게임플레이 코드는 아직 작성하지 않았다.
