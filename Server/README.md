# 인터넷 방 서버 실행

Python 3가 설치된 공개 호스트에서 `python3 Server/rooms.py`를 실행합니다. 서버는 8787 포트에서 요청을 받습니다. HTTPS 주소로 들어오는 요청을 이 포트로 전달하고, 게임을 빌드하기 전에 DriftApplication의 Room Server Url에 해당 HTTPS 주소를 입력하세요. 테스트할 때는 게임 또는 Unity Editor를 실행하기 전에 환경 변수 DRIFT_ROOM_URL로 주소를 지정할 수 있습니다.

방 정보는 메모리에 보관되므로 서버는 한 프로세스로 실행하세요. 서버 재시작 시 방이 초기화됩니다. 호스팅 서비스가 PORT 환경 변수를 설정하면 서버는 해당 포트를 사용합니다. 현재 공유하는 상태는 항구의 명단, 준비 여부, 출항 결정, 승선 후 선박 기준 위치와 방향, 선원별로 현재 들고 있는 아이템, 공동 조타와 선박 위치, 기본 갑판 아이템 및 플레이어가 떨어뜨린 아이템, 정수기 저장량과 정수 타이머, 네 가지 일일 작업의 완료 여부 및 이야기 진행 단계입니다.

## Render에서 주소 만들기

이 프로젝트를 담은 저장소를 Render의 New > Blueprint에서 선택하면 루트의 render.yaml이 방 서버 하나를 설정합니다. 배포 후 서비스 화면의 HTTPS 주소를 사용하세요. 서버 확인은 해당 주소의 /health 에서 할 수 있습니다. 방 번호는 게임 안에서 방 만들기를 눌렀을 때만 발급됩니다.
